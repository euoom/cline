# euoom Cline 커스터마이즈

이 포크는 Cline Hub와 웹 대시보드를 개인 로컬 에이전트 작업 환경에 맞게 보완한 버전이다. 업스트림 Cline의 일반 기능을 대체하기보다, 웹과 IDE에서 같은 작업 맥락을 이어 가는 데 초점을 둔다.

## 반영 사항

### Hub 기반 세션 공유

- IDE 확장과 웹 대시보드가 동일 Cline Hub를 통해 세션을 사용한다.
- 웹에서 생성·선택한 세션의 대화 이력과 실행 상태를 Hub 기준으로 조회한다.
- Hub가 재시작되어 메모리 런타임 세션을 잃은 경우, 저장된 대화 이력으로 세션을 복원한 뒤 원래 메시지를 다시 전송한다.
- 첫 사용자 메시지를 세션의 작업 제목으로 저장해 세션 목록에서 식별하기 쉽게 했다.

### 웹 작업 설정

- 새 세션은 기본 워크스페이스를 제안하지만, 웹 UI에서 원하는 작업 경로로 변경할 수 있다.
- 웹 UI에서 provider와 model을 선택해 세션을 시작하거나 다음 턴의 실행 모델을 바꿀 수 있다.
- 실행 중 모델을 바꾸면 현재 턴은 그대로 완료하고, 선택한 모델은 다음 턴부터 적용한다.
- 세션을 다시 열거나 새로고침할 때는 Hub 요약 캐시 대신 실제 세션 레코드의 모델을 우선해 마지막 실행 모델을 복원한다.

### 프롬프트 환경 정보

- Cline 시스템 프롬프트의 날짜와 시간을 `Asia/Seoul` 기준으로 생성한다.
- 시스템 프롬프트에 현재 KST 시각을 명시해 시간 의존적인 요청의 기준을 일관되게 제공한다.

## 검증 범위

- Hub 서버/웹뷰 TypeScript 타입 검사
- Hub 웹뷰 프로덕션 빌드
- Hub 재시작 뒤 기존 세션의 이어가기 및 모델 전환 동작 확인

## 관련 코드

- `apps/cline-hub/src/server.ts`: 웹 명령 처리와 다음 턴 모델 동기화
- `apps/cline-hub/src/server/sessions.ts`: 세션 수화·복원·재전송
- `apps/cline-hub/src/webview/src/Chat.tsx`: 웹 모델 선택 UI 동작
- `sdk/packages/core/src/hub/server/handlers/run-handlers.ts`: 첫 프롬프트 저장
- `sdk/packages/shared/src/prompt/`: KST 기반 시스템 프롬프트 환경 정보
